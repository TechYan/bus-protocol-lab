# Bus Protocol Lab

Small visual tools for bus protocol learning and debug.

## Demos

- [Demo](axi4-atomic-format-table.html)
- [PCIe TLP split demo](pcie-tlp-split-demo.html)

Open the HTML files directly in a browser.

The Demo is an interactive AXI4 atomic byte-lane view for memory selection, DNOC internal reqdata placement, and IP-facing AXI wstrb/wdata placement.

The PCIe demo visualizes Memory Read Request splitting, byte enable behavior, and Completion with Data splitting under MRRS, MPS, RCB, and 4 KB boundary constraints.
