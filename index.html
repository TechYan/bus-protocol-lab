Split logic

DW envelope

Green means enabled/valid. Dark bytes are masked in a request or padded in a completion.
MemRd request fields
PCIe read requests are DW-oriented. The address field is DW aligned, while FBE/LBE describe the real byte window in the first and last DW.
Completion fields
Completions use Byte Count and Lower Address, not BE. The data payload may still occupy a partial last DW.
4KB rule
Read requests do not cross a 4KB boundary. Completions also stop at a 4KB boundary.
What the colors mean
Green byte lanes are enabled by BE or returned as valid completion bytes. Amber marks 4KB page starts.
